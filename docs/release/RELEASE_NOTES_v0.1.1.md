# MSH v0.1.1 正式第一版候選版（未發布／委託方檢閱用）

## 本版更新

- 新增 **說明 > 檢查更新...**，可手動確認是否有新版本。
- 啟動後會在背景進行一次靜默版本檢查；離線或更新服務暫時不可用時不會阻止 MSH 操作。
- 發現新版本時顯示版本號、發布日期、更新說明與安裝檔 SHA-256。
- 只有在使用者確認後才會開啟瀏覽器下載；MSH 不會在背景自動下載或執行未簽署安裝檔。
- 維持固定的 Inno Setup `AppId`，讓新版安裝程式可覆蓋更新既有 MSH 安裝。
- 第一版預設使用 `wbc_focus_yolov8n_e_20260611.pt` 進行 WBC-only detection；可繪製白血球框，但不分類白血球亞型。

## 發布與驗證狀態

- 107/107 軟體測試通過。
- CPU PyInstaller 與 Inno Setup 建置通過，已確認更新模組與核准的 WBC 模型包含在安裝內容中。
- WBC 模型可正常以 CPU 載入；對冷備份的 9 張 validation 影像進行唯讀煙霧測試時，8 張產生 WBC 偵測框。
- 公開更新資訊與安裝檔將由 release-only repository 提供，不會在應用程式內嵌 GitHub Token。

## 已知限制

- 此檢閱版尚未進行公開程式碼數位簽章，Windows 或防毒軟體仍可能顯示未知發行者警告。
- 正式發布前仍需完成跨版本覆蓋安裝、無 Python 電腦與必要的 B 地硬體驗證。
- WBC 模型授權、來源與實際效能必須依最終核准模型另行確認。
- WBC 模型的公開散布授權仍需確認；模型存在於冷備份不等同於已授權公開上傳。
