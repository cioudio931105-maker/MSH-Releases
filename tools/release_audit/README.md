# 本機 Artifact 盤點與審閱

此工具讀取檔名、容量與模型檔雜湊，產生離線 `index.html`、`inventory.json`
及完整 `files.jsonl`。不載入模型、不讀取影像內容、不上傳、不搬移或刪除原檔。
Git／Codex 內部目錄、其他 worktree、junction／symlink 和報告目錄會略過。

從專案根目錄執行：

```powershell
.\.venv312-cpu\Scripts\python.exe tools\release_audit\inventory.py --output tmp\release-artifact-review
```

以瀏覽器開啟輸出的 `index.html`。可以依路徑、類別與審閱標記篩選，切換模型、
資料群組或完整檔案清單。完整清單需由使用者選入同目錄 `files.jsonl`。
「匯出審閱決策」只下載 JSON，不執行任何刪除；其 `delete_authorized` 固定為 false。
標記保存在目前瀏覽器的 localStorage，換瀏覽器或清除資料前請先匯出。

每列提供「用途與刪除影響」視窗，分別說明來源版、獨立安裝版、涉及功能、
刪除後果、建議、判斷依據及限制。可搜尋用途或按刪除影響篩選；模型頁能分開
查看 PT／訓練／測試權重及舊 pylon OCR 資源。它們不能全被當成白血球模型。
「全部檔案」同時顯示單檔類型與上層整個群組的影響，兩種刪除範圍不可混淆。
資料群組中的訓練資料會再解釋原圖、待複核標註、外部參考及小型五類參考的差別。

說明由 `explanations.py` 依已核對的程式引用、目錄內容及本機歷史文件建立，
不載入 checkpoint，也沒有逐項實做刪除實驗。未覆蓋的新目錄標為用途未確認；
不會因為位於 tmp、dist 或被 Git 忽略，就推論可刪除。外部腳本、已選模型、
其他人的捷徑及外部備份是否仍可用，未經查核不得宣稱已排除影響。
既有決策 ID 及 localStorage key 保持，因此更新清單不會自動清除使用者標記。

原始／示範模型會核對 SHA-256；環境、封裝與一般測試副本不因此全部雜湊。
只有已計算且完全相同的 SHA-256 才列為確定重複。相同大小不代表相同檔案，
而相同檔案也不代表可刪除最後一份。舊安裝包可能含模型，不可視為目前純應用程式版。
任何刪除都須另外核對使用者選定項目、備份、目前使用者及精確路徑。

工具拒絕覆寫非本工具建立的非空目錄。重新盤點會更新既有報告，不會更動原資料；
Git 歷史、其他硬碟及其他機器的資料不在本次目錄盤點範圍。
