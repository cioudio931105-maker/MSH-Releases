## Build-directory finding

No original `dist/release/v0.1.3`, `dist/cpu/MSH`, or release-staging directory
was found in the inspected current checkout, Codex worktree, or named historical
project copies. The currently active audit worktree was created after the build.
The likely source was a now-removed worktree on the client-update branch, but its
absolute path cannot be established from preserved evidence and must not be
reported as fact.

## Validation known at audit time

Persistent work state records successful v0.1.3 installation and confirmation
that its UI reflects the previously approved changes. Functional testing was
still in progress. No complete reopen/uninstall/residual-process result, live
update-delivery result, clean-machine result, or B-site hardware validation was
found as version-specific evidence.

## Disposition

Treat v0.1.3 as a preserved, checksum-verifiable client-review artifact, not as a
fully reproducible public release. Do not overwrite or rebuild under the same
version. Future releases must be produced from a clean tagged commit and finalized
as one immutable version bundle using `scripts/finalize_release_bundle.ps1`.

The WBC model record identifies an embedded AGPL-3.0 checkpoint license, but no
separate redistribution approval for the trained weight or its training data was
found in the returned evidence. Public model distribution remains blocked until
the project owner records the applicable data rights and chooses an Ultralytics
licensing path.
