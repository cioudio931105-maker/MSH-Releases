# MSH 官方識別 V1

狀態：正式第一版（2026-08-19）

此版本是 MSH 桌面捷徑、GUI 視窗圖示與啟動動畫共用的正式視覺基準。後續設計應以新版本資料夾保存，禁止覆寫本目錄的檔案。

## 設計基準

- 主題：卡通風格的賽博龐克顯微鏡掃描工作環境。
- 文字：斜向、銳利的 `MSH` 字標；左側青藍、右側紫色，黑色字面。
- 視覺：霓虹外暈、破碎且散亂的像素殘影、掃描網格與細胞意象。
- 動態：啟動畫面僅使用低調的碎裂像素；不使用水平掃描線、準星或垂直雷射。

## 檔案對應

| 用途 | 正式檔案 |
| --- | --- |
| Windows 捷徑與 GUI 圖示 | `msh-pixel-icon-v1.ico` |
| 圖示原圖 | `msh-pixel-icon-v1.png` |
| 啟動畫面原圖 | `msh-cyberpunk-splash-v1.png` |
| 程式使用的 640×360 啟動畫面 | `msh-cyberpunk-splash-640-v1.png` |

目前程式實際使用的 `assets/msh-pixel-icon.*` 與 `assets/msh-cyberpunk-splash*.png` 皆與本版本相同。
