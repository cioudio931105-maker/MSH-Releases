## 醫師標註規則

三分類偵測模型的固定類別與 YOLO ID：

```text
0 = WBC
1 = RBC
2 = Platelets
```

每張影像需確認：

1. 是否可判讀；模糊、失焦、嚴重染色異常或重複畫面請標記為 `exclude`，保留原檔但不放入訓練集。
2. 每個目標細胞是否有正確 bounding box；補上漏檢、移除誤檢、修正框大小與類別。
3. 醫師無法確定的物件標為 `review`，不可直接強迫標成任一類別。
4. 同一病人／同一血片／同一次掃描的影像必須放在同一資料 split；不可分散到 train、validation、test，避免資料洩漏。

標註完成後，才可將醫師簽核的影像與 `.txt` YOLO label 移入新的 `gold_reviewed` 資料集。既有的 `02_*` 只屬候選標註，不能直接宣稱為人工 ground truth。

## AI 訓練前品質門檻

- 先建立影像層級、血片層級與病人層級的去識別化 ID；不在檔名、CSV 或 label 中記錄姓名、病歷號等個資。
- 為每一類記錄影像數、box 數、排除數、來源 slide 數與標註醫師／版本。
- 保留獨立的 slide-level validation 與 test set；不以訓練集結果取代臨床驗證。
- 特別檢查 Platelets，因過往三分類訓練中它最容易退步。
- 新模型只有在各類別指標、特別是 Platelets，以及獨立血片的醫師檢視都優於既有基準後，才能替換 GUI 預設模型。
